# Dataset

This folder contains the datasets used in the Indian Banking Transactions Analysis project.

## Files

1. **Indian_Banking_data.xlsx** – Original banking transaction dataset.
2. **Indian_Banking_Transactions_Analysis.xlsx** – Final Excel workbook containing the raw data, cleaned data, data quality checks, PivotTables, dashboard and Data Dictionary.

These files are used for data cleaning, analysis and visualization using Microsoft Excel.
